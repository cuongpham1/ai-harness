## Flutter Stack

| Doc | When to read |
|-----|-------------|
| docs/FLUTTER_STACK.md | Before Dart/Flutter implementation |

### Commands
- Test: `flutter test`
- Lint: `flutter analyze`
- Run: `flutter run`

### Rules
- Widget tests for UI components
- Use `flutter gen-l10n` for user-visible strings
- Prefer layered architecture: domain → data → presentation

### Skills
- `/flutter-run` — launch on device/simulator
- `/flutter-test` — run tests
